## Running the Project Locally

### Clone the Repository

```bash
git clone https://github.com/tdrdevs/TDRDEVS-Website.git
```

### Navigate to the Project

```bash
cd TDRDEVS-Website
```

### Run the Website

The website can be opened by launching `index.html` in a web browser.

For development, you can also use a local development server such as the **Live Server extension in Visual Studio Code**.
